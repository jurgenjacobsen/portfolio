## Welcome to the Knowledge Guides

Welcome! This space is a curated technical repository created to document aviation standard operating procedures, modern software engineering architectures, and developer workflows in a structured, distraction-free format.

### How It Works

- **Explore Topics:** Use the **Directory** sidebar on desktop or the mobile **Browse Directory** bar to navigate through sections and topics.
- **Instant Access:** Each guide is rendered on-demand from Markdown for fast reading and lightweight loading.
- **Track Progress:** Use the **Mark as Read** button at the bottom of each article to save your completed reading list locally.
- **Share:** Deep-link directly to any guide using the **Copy Link** and **Share Guide** buttons.
